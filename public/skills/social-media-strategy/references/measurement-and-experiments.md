# Measurement and Experiments

Use this reference to make the strategy learnable.

## Measurement model

Measure a chain, not a vanity metric in isolation:

| Layer | Example question | Example measures |
| --- | --- | --- |
| Delivery | Did the intended audience receive useful content? | qualified reach, completion, watch or read depth |
| Response | Did the audience show meaningful interest? | saves, shares, substantive replies, repeat engagement |
| Progression | Did attention become a next step? | qualified visits, subscriptions, registrations, product actions |
| Business outcome | Did the work contribute to the stated objective? | qualified leads, opportunities, retention, revenue, applications |

Define each measure's formula, reporting period, source, owner, and limitation. A platform metric is not evidence of business impact by itself. Document attribution assumptions and avoid claiming sole causation where multiple touchpoints are involved.

## Instrumentation minimum

Before judging conversion, define a consistent campaign or content identifier, destination parameters where appropriate, the desired next action, and the data source used to connect outcomes. If this instrumentation is unavailable, report the limitation and use directional learning rather than invented ROI.

## Experiment card

Use one card per test:

| Field | Definition |
| --- | --- |
| Hypothesis | If we change [variable] for [audience], [measure] will change because [reason]. |
| Variable | One primary difference: message, proof, format, offer, channel, distribution, or cadence. |
| Constant | What remains comparable. |
| Window | Start, end, and minimum observation period. |
| Success measure | The preselected measure and threshold or directional criterion. |
| Decision rule | Expand, iterate, pause, or stop based on the result. |
| Owner | Person or role responsible for running and reviewing it. |

Avoid treating a single high-performing post as a durable rule. Review enough comparable pieces to distinguish a useful signal from novelty, distribution variation, or an external event.

## Review rhythm

- Weekly: production blockers, audience response, community signals, and experiment execution.
- Monthly: pillar and format performance, channel fit, conversion progression, and resource allocation.
- Each planning cycle: retain, revise, or remove channels and themes based on evidence.
