# Lifecycle e Avaliação de Prompts

Uma alteração de prompt é uma mudança de configuração. Registre versão, hipótese, conjunto de avaliação, modelo, harness, skills e resultado. Compare com baseline antes de promover e mantenha caminho de rollback.

Avalie tanto o resultado final quanto a trajetória quando o agente usa ferramentas. Use validadores determinísticos para contratos objetivos, rubricas independentes para qualidade semântica e revisão humana antes de tornar um score semântico um gate rígido.

Consulte `sistemas-agenticos-observabilidade` para tracing e `sistemas-agenticos-metodologias` para rollout e ADR.
