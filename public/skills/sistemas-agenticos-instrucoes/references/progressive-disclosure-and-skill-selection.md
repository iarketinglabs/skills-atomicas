# Disclosure Progressivo e Seleção de Skills

Use metadata para descoberta, instruções completas apenas após seleção e recursos somente quando a tarefa os exigir. Isso reduz contexto irrelevante sem esconder regras críticas.

Promova um procedimento a skill quando ele for recorrente, tiver gatilho reconhecível, contrato de saída e validação repetível. Mantenha uma instrução curta no prompt quando ela for um invariante que se aplica a toda interação.
