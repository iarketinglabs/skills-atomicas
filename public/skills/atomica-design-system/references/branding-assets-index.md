# Assets de marca

O pacote inclui CSS de referência com textura gerada por gradientes. Para identidade exata, confirme direitos e origem de logos, fotografias, fontes e texturas antes de os mover para o projeto. Obtenha as fontes abertas no repositório oficial e preserve as licenças. A fonte opcional Atomica Script exige uma cópia autorizada.

Fontes de distribuição aberta: [Jost](https://github.com/google/fonts/tree/main/ofl/jost), [Oswald](https://github.com/google/fonts/tree/main/ofl/oswald), [Bebas Neue](https://github.com/google/fonts/tree/main/ofl/bebasneue), [Caprasimo](https://github.com/google/fonts/tree/main/ofl/caprasimo) e [Fontdiner Swanky, Apache 2.0](https://github.com/google/fonts/tree/main/apache/fontdinerswanky).
