# Glossário de IA (simples, com traduções)

Objetivo: qualquer marketer entender.

Regra: termo técnico aparece uma vez → definição simples → exemplo.

| Termo | Definição simples | Exemplo/metáfora |
|-------|-------------------|------------------|
| **LLM** | modelo que gera texto e raciocina a partir de instruções e contexto | "estagiário muito rápido" |
| **IA generativa** | IA que cria conteúdo novo (texto, imagem, vídeo, áudio) | — |
| **Prompt** | instrução que você dá para a IA | o "briefing" |
| **Contexto** | informações que a IA usa para responder | documentos, exemplos, regras |
| **Memória** | o que o sistema consegue reter e reutilizar ao longo do tempo | quando habilitado |
| **RAG** | técnica para a IA buscar informação em uma base de conhecimento antes de responder | "consultar um arquivo" |
| **Agentes** | automações que tomam passos (buscar, decidir, executar) para chegar num resultado | — |
| **Automação** | conectar sistemas e tarefas para reduzir trabalho repetitivo | — |
| **Trigger** | gatilho que inicia a automação | — |
| **Webhook** | "porta" para receber/enviar dados entre sistemas | — |
| **Integração / API** | forma padronizada de um sistema conversar com outro | — |
| **Input / Output** | o que entra / o que sai | — |
| **Alucinação** | quando a IA inventa (parece confiante, mas não é confiável) | — |
| **Reasoning** | capacidade de encadear passos | melhor com contexto e boas instruções |
| **Vibe marketing** | orquestrar IA para transformar ideia em execução com fluidez, sem barreiras de expertise | — |
| **Vibe coding** | construir soluções com ajuda de IA (mais rápido, iterativo, com prototipagem) | — |
| **AI slop** | conteúdo genérico e sem alma, feito em massa sem critério | — |
| **CLI** | interface de linha de comando (texto) para operar ferramentas | — |
| **IDE** | ambiente de desenvolvimento (onde você programa) | — |
| **MCP** | protocolo para conectar modelos e ferramentas/contextos | — |
