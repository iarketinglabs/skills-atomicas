# Plataformas Gerenciadas e Deploy por CLI

Plataformas gerenciadas reduzem trabalho operacional, mas introduzem limites, dependência de fornecedor e modelo de custo próprio. Deploy via CLI pode ser auditável e automatizável, desde que a identidade, os ambientes, a configuração e a reversão sejam controlados.

Antes de escolher, compare: requisitos de disponibilidade, domínio de operação, limites de execução, egress, política de dados, portabilidade, logs, rollback e custo por demanda. Não codifique uma plataforma como premissa de uma skill reutilizável.
