# Instruções Não São Boundaries de Segurança

System prompts e guardrails orientam comportamento, mas não substituem autorização, validação de argumentos, escopos de ferramenta ou isolamento. Conteúdo não confiável deve ser tratado como dado durante a montagem de contexto, mesmo quando parece instrução útil.

Mantenha enforcement no boundary de ferramenta ou dado. Consulte `sistemas-agenticos-instrucoes` para hierarquia e proveniência de contexto.
