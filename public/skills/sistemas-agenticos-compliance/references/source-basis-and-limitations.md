# Base temática e limites

Esta skill oferece um método para identificar, pesquisar e documentar obrigações aplicáveis. Não é um parecer jurídico nem uma fotografia permanente da legislação. Não use uma lista de temas como prova de aplicabilidade a uma entidade, sistema ou finalidade.

Para uma análise concreta, siga a hierarquia e o procedimento de [regulatory-research-and-evidence.md](regulatory-research-and-evidence.md). Consulte o texto oficial e as alterações vigentes na data da análise; registe jurisdição, papel, artigo ou seção, versão, data de consulta e qualquer ponto não confirmado. Separe fato organizacional, hipótese e interpretação jurídica.

Os links de partida não formam uma lista exaustiva. A skill deve identificar fontes equivalentes na jurisdição relevante e confirmar se a fonte é oficial e atual. Nunca apresente cronogramas, classificações ou conclusões de pesquisas anteriores como vigentes sem reconfirmação independente.
